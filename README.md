# WARAQ — مساعد ورق

تطبيق ويب عربي لإدارة المواد والمحاضرات والامتحانات والمهام، مع مساعد ذكي يعمل بالعربية.
الواجهة ثابتة بالكامل وتُنشر على **GitHub Pages**، والبيانات تُخزّن محلياً وتُزامن مع Supabase عند تسجيل الدخول.

## البنية

```
index.html                       الواجهة كاملة (HTML + CSS + JS)
config.js                        رابط Supabase والمفتاح العام (آمن للنشر)
supabase/schema.sql              الجداول وسياسات RLS و Storage وجدول chunks
supabase/functions/chat/         Edge Function قديمة (غير مستخدمة بعد تحويل المساعد لمفتاح المستخدم)
.github/workflows/deploy-function.yml   نشر الدالة تلقائياً
push.ps1 / رفع التحديث.cmd       رفع التعديلات بضغطة واحدة
build-apk.ps1 / npm run apk       بناء نسخة أندرويد (APK)
capacitor.config.json            إعدادات غلاف Capacitor
android/                          مشروع أندرويد المولّد
scripts/copy-web.js               نسخ الواجهة إلى www قبل البناء
scripts/make-icons.ps1            توليد أيقونة ورق لأندرويد
apk/WARAQ-debug.apk               النسخة الجاهزة للتثبيت على الهاتف
```

## التحديث اليومي (بدون نقل ملفات يدوياً)

1. عدّل الملفات داخل هذا المجلد.
2. انقر مرتين على `رفع التحديث.cmd`، أو نفّذ:
   ```powershell
   .\push.ps1 "وصف التعديل"
   ```
3. يرفع السكربت التغييرات إلى `main`، ويتولى GitHub Pages تحديث الموقع تلقائياً.

> إذا كنت تعدّل من نسخة أخرى من الملفات، انسخ التعديل إلى هذا المجلد أولاً — هذا المجلد هو المستودع المرتبط بالموقع المنشور.

## إعداد Supabase (مرة واحدة)

1. افتح **SQL Editor** ونفّذ محتوى `supabase/schema.sql`.
2. تأكد من إعدادات الأمان في لوحة Supabase:
   - `Confirm email` و`Secure email change` = ON
   - `Leaked password protection` و`CAPTCHA` = ON
   - مدة صلاحية JWT = 3600 ثانية
3. المساعد لا يحتاج أي سر عندك: كل مستخدم يدخل مفتاح Google AI Studio الخاص به من **المزيد ← الحساب**، والمتصفح يتصل بـ Gemini مباشرة. لا حاجة لنشر دالة `chat` ولا لـ `GEMINI_API_KEY`.

### أسرار GitHub Actions (اختيارية — للدالة القديمة فقط)

في **Settings → Secrets and variables → Actions** أضف:

| الاسم | القيمة |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | من https://supabase.com/dashboard/account/tokens |
| `SUPABASE_PROJECT_REF` | معرّف المشروع من رابط لوحة التحكم |

⚠️ لا تضع أبداً `sb_secret_...` أو `service_role` داخل `config.js` أو أي ملف في هذا المستودع.

## المساعد الشخصي والذاكرة

- كل مستخدم يدخل مفتاحه الخاص (Google AI Studio ← Get API key) في **المزيد ← الحساب**. المفتاح يُحفظ في `localStorage` على جهازه فقط، ويُرسل مباشرة إلى `generativelanguage.googleapis.com` — لا يمر عبر خادمنا ولا يُحفظ في المستودع.
- بدون مفتاح، الضغط على «إرسال» يفتح صفحة الحساب. رسائل الخطأ تفرّق بين مفتاح غير صالح ونفاد الحصة ومشكلة إنترنت.
- حصة الطلبات صارت على مفتاح المستخدم في Google، لا على مشروع Supabase.
- المحادثة تستخدم **Interactions API** مع `gemini-3.8-flash`، ومع قائمة احتياطية (`gemini-3.7-flash`، `gemini-3.6-flash`، `gemini-3.5-flash`، `gemini-3.1-flash-lite`) إذا ظهر ضغط مؤقت أو تعذّر وصول للموديل. الموديل القديم `gemini-2.5-flash` لم يعد متاحاً للمستخدمين الجدد.
- فهرسة PDF واسترجاع المقاطع صارا في المتصفح بنفس المفتاح (نموذج `gemini-embedding-001`)، والمقاطع تُحفظ في جدول `chunks` الذي أضفناه إلى `schema.sql` — لازم تنفّذ الملف في Supabase مرة أخرى.
- المساعد يحفظ ما تخبره به عنك في `profile.facts` عبر أداتي `remember` / `forget`، ويرسل السياق داخل `system_instruction` ليتذكر اسمك وتفضيلاتك.
- لتغيير الموديلات عدّل `GEMINI_MODELS` و`EMBED_MODEL` في أعلى سكربت `index.html`.

ترتيب التبويبات: الرئيسية، الجدول، المواد، المساعد، المزيد. عند دخول أي محادثة يتم التمرير تلقائياً إلى آخر رسالة.
زر `/` بجانب تبويبات المحادثات يفتح قائمة الأوامر: `/clear` يمسح كل رسائل المحادثة الحالية فقط (لا يمكن التراجع).

## ملاحظات أمنية

- `config.js` يحتوي على **مفتاح عام** فقط، وهو آمن في مستودع عام.
- الحماية الفعلية تعتمد على سياسات RLS في `schema.sql` — بدونها أي مفتاح عام يكشف بيانات المستخدمين.
- الدالة `chat` القديمة لم تعد مستخدمة؛ المحادثة والفهرسة بين المتصفح وGoogle بمفتاح المستخدم، بينما تسجيل الدخول مطلوب لمزامنة البيانات وتخزين المقاطع.
- ملفات PDF خاصة، ومجلد كل مستخدم معزول، والحد الأقصى 15MB ونوع الملف مُقيّدان على الخادم.
- أضيفت رؤوس CSP (تسمح بـ Google وcdnjs فقط) و`referrer` وSRI لسكربتَي Supabase وpdf.js في `index.html`.

## تطبيق أندرويد (Capacitor APK)

الـ APK جاهز في `apk/WARAQ-debug.apk` — انقله إلى هاتفك وافتحه، ثم اسمح بالتثبيت من «مصادر غير معروفة» عند الطلب. التطبيق يحمل نسخة من الواجهة، فلا يحتاج إنترنت ليفتح، لكن المساعد وPDF يحتاجان مفتاح Gemini الخاص بك كما في الموقع.

لبناء نسخة جديدة بعد أي تعديل على `index.html`:

```powershell
npm install          # مرة واحدة فقط
npm run apk          # أو: powershell -File build-apk.ps1
```

السكربت ينسخ الويب إلى `www`، يزامن Capacitor، يبني APK عبر Gradle، ويضع الناتج في `apk/WARAQ-debug.apk`.

**متطلبات البناء على هذا الجهاز:** Node.js (مثبّت)، JDK 21، وAndroid SDK (منصة 36 + Build Tools). لأن مسار المستخدم فيه أحرف عربية، يبني السكربت داخل `C:\waraq-build\project` (مسار ASCII) لتفادي مشاكل Gradle مع المسارات غير اللاتينية. أيقونة التطبيق مولّدة من `scripts/make-icons.ps1` ويمكن إعادة توليدها بـ `npm run icons`.

> النسخة الحالية `debug` وموقّعة بشهادة تطوير، مناسبة للتثبيت المباشر على هاتفك. عند النشر في Google Play نحتاج توقيع release ورفع AAB بدلاً من APK.
